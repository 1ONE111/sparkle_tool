블로거 서쳐 1.1 — Windows 64비트

1. 블로거서쳐.exe를 실행합니다.
2. 레퍼런스 네이버 블로그 주소를 1~10개 붙여 넣거나 TXT를 불러옵니다.
3. 캠페인 조건을 추가 검색어에 쉼표로 구분해 입력합니다. 비워 두면 레퍼런스의 최근 글에서 검색어를 만듭니다.
4. 기존 컨택 주소가 있다면 제외할 주소 TXT를 불러옵니다.
5. '후보 찾기'를 누릅니다. 검색 중에도 중단할 수 있습니다.
6. 후보를 더블클릭해 콘텐츠를 확인합니다. 필요한 후보를 선택해 TXT로 저장합니다.
7. 저장한 TXT를 기존 크롤러에 입력합니다. 헤더 없이 블로그 홈 주소만 한 줄씩 저장합니다(UTF-8 BOM).

앱 왼쪽 아래 '사용 방법 · 크롤러 연계'를 누르면 위 순서와 크롤러의 '블로그 정보 → 파일 불러오기 → 수집 시작 → 엑셀 저장' 안내를 볼 수 있습니다. 안내는 EXE 안에 포함되어 별도 파일이 필요하지 않습니다.

후보 정렬 기준
- 최근 공개 글 최대 25개의 제목에서 단어를 추출합니다.
- 레퍼런스와 후보의 단어 빈도 벡터를 비교한 코사인 유사도 × 100입니다.
- '주제 겹침'은 제목의 단어 일치 정도이며, 광고 적합성이나 사진 퀄리티를 보장하는 점수가 아닙니다.
- 최근 글은 공개 RSS에 표시된 최신 날짜를 한국 시간으로 변환합니다.
- 닉네임 조회가 제한되면 RSS의 블로그명을 표시하며 로그에 남깁니다.
- 레퍼런스 본인과 제외 목록은 결과에서 빠집니다. 공개 최근 글을 확인하지 못한 후보도 제외합니다.
- 목표 수보다 적게 나올 수 있습니다. 공개 검색 결과 범위 안에서 찾으며, 최대 300개 후보를 검사합니다.

검색 연결
- 기본: 네이버 공개 웹 검색. 로그인과 API 키 없이 동작합니다. 검색 화면 변경이나 접근 제한에 따라 실패할 수 있습니다.
- 선택: 오른쪽 위 '검색 설정'에서 네이버 검색 API의 Client ID와 Client Secret을 입력하면 공식 검색 API를 사용합니다.
- 실행 내역은 오른쪽 아래 '실행 로그 보기'에서 확인합니다.
- API 키는 앱에서 파일로 저장하지 않습니다. 네이버 개발자센터에서 검색 API 사용 권한이 있는 앱으로 발급합니다.
  https://developers.naver.com/docs/serviceapi/search/blog/blog.md
- 접근 제한을 우회하지 않습니다. 제한 발생 시 중단하거나 공식 API 연결로 재시도합니다.

실행 환경
- Windows 10/11 64비트, .NET Framework 4.8 이상 권장. 이 PC에서 64비트로 빌드했습니다.
- 인터넷 연결이 필요합니다. 외부 AI 서비스에 블로그 목록을 보내지 않습니다.
- EXE는 코드 서명되지 않은 초기 버전입니다.
- 소스코드는 src 폴더, 검증 기록은 tests 폴더에 있습니다.
