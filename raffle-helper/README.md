# 추첨 도우미

카페 소문내기 이벤트의 네이버폼 응답(raw)을 넣으면, 게시글을 자동으로 확인해서 당첨자 리스트 엑셀을 만들어 주는 Windows 프로그램입니다. 설치 없이 `추첨도우미.exe`를 바로 실행하면 됩니다.

## 하는 일
- **raw 불러오기**: 네이버폼 raw 엑셀을 창에 끌어다 놓거나 '파일 선택'으로 엽니다. 이벤트 이름은 파일 이름에서 가져옵니다.
- **게시글 확인**: 네이버 카페(naver.me 포함)와 디시 글은 자동으로 읽습니다. 조회수, 카페 가입자 수, 링크·이미지·표 여부를 확인합니다. 뽐뿌처럼 자동으로 읽히지 않는 사이트는 '직접 검토'로 보냅니다.
- **댓글 확인**: 공식카페 이벤트 글의 댓글 작성자 닉네임과 폼의 닉네임을 대조합니다.
- **직접 검토**: 메인 화면 위에 시트로 뜹니다.
  - 뽐뿌: 조회수와 정성도를 직접 넣습니다.
  - 복붙의심·댓글 미확인: '인정'이나 '제외'를 누릅니다.
- **엑셀 내보내기**: 지금 쓰는 당첨자 리스트와 같은 모양으로 저장합니다. 파일 이름 끝에 오늘 날짜(YYMMDD)가 붙습니다.
- **당첨 이력**: 추첨 뒤 노란색을 칠한 최종 리스트를 불러오면 월별로 기록합니다. 선착순 당첨자는 발표일부터 3개월 동안 선착순에서 자동으로 빠집니다. 월별 안에서 기록을 추가하거나 지울 수 있고, 월별 엑셀로도 저장할 수 있습니다.

## 판정 규칙 (기본값, 설정에서 바꿀 수 있음)
- **제외**: 다음카페, 캐시닥·캐시워크, 개인 채널(블로그·인스타그램·X 등), 삭제된 글, 전체 공개가 아닌 글, 가입자 3만 명 이하 카페, 조회수 10 미만 글
- **중복**
  - 같은 게시글을 여러 사람이 냈으면 먼저 낸 사람만 인정합니다(중복 게시글).
  - 한 사람이 같은 커뮤니티에 2건 이상 냈으면 조회수가 많은 1건만 인정합니다(커뮤니티 중복).
- **특별 미션**: 인정된 글의 조회수를 합해 300 이상이면 추첨 대상입니다. 추첨은 유니피커로 합니다.
- **선착순**: 인정된 사람을 원래 제출 순서(참여자 번호)대로 줄 세웁니다. '(수정)' 응답도 원래 자리에 둡니다.
- **3개월 이력**: 3개월 안에 선착순에 당첨됐으면 선착순에서 뺍니다. 특별 미션은 그대로 가능합니다.
- **정성도**
  - 상: 링크 + 이미지, 또는 링크 + 표
  - 중: 이미지, 표, 링크 중 하나
  - 하: 글만
  - 여기서 '링크'는 설정의 '확인할 링크'로 시작하는 주소입니다.
- **복붙의심**: 본문이 90% 이상 같으면 먼저 올라온 글은 그대로 두고, 나중 글을 직접 검토로 보냅니다.

## 파일
- `추첨도우미.exe`: 프로그램
- `설정.ini`, `당첨이력.csv`: 처음 쓸 때 exe 옆에 생깁니다. 이 저장소에는 올리지 않습니다(당첨자 정보가 들어 있음).
- `src\Core.cs`: raw 읽기, 게시글 확인, 판정, 엑셀 읽고 쓰기, 당첨 이력
- `src\Ui.cs`: 화면

## 빌드
Windows에 들어 있는 .NET Framework 컴파일러(csc)로 빌드합니다. 따로 설치할 것은 없습니다.

```powershell
.\build.ps1
```

## 인터넷 사용
네이버 카페·디시의 공개 글 정보(조회수, 본문, 댓글 닉네임)를 읽을 때만 인터넷을 씁니다. raw 파일의 이름·연락처는 프로그램 밖으로 보내지 않습니다.
