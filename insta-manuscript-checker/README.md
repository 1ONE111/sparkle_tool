# 원고 검수기 - 인스타

[원고 검수기](https://github.com/1ONE111/sparkle_tool/tree/feature/manuscript-checker/manuscript-checker)(블로그)의 인스타 버전.
원고(.docx)와 인스타 캡션을 대조해서 원고에 표시한 수정 사항이 반영됐는지 확인하고, 같은 검수 엑셀 양식으로 저장한다.

설치 없음. `원고검수기_인스타.html` 을 크롬 · 엣지로 열면 된다.
인스타는 브라우저에서 게시물을 직접 읽을 수 없어서 캡션은 복사해 붙여넣는다.

## 사용법

1. 원고(.docx)를 창에 끌어다 놓거나 `원고 여러 개 넣기`. 이름은 파일 이름 끝의 닉네임으로 채워진다 (예: `…원고_닉네임_검수.docx`)
2. 인스타 게시물 · 릴스 링크를 넣는다. 링크 여러 줄을 한 칸에 붙여넣으면 아래 행으로 나눠 들어간다
3. 행을 고르고 아래 `캡션` 칸에 캡션을 붙여넣는다 → 바로 검수. 첫 댓글에 해시태그를 단 경우 그것도 같이 붙여넣는다
4. `수정사항` 에서 문구를 고친다. 글자를 드래그해 `빨간 글씨` 로 바꾸면 엑셀에서도 빨간색. `참고` 항목은 누르면 수정사항에 추가
5. `엑셀 내보내기` → `시트 이름(게시일)` 시트, B2부터 `순서 | 이름 | URL | 수정사항`. 수정사항이 있는 행은 이름 칸이 빨간색

원고 · 캡션은 브라우저 안에서만 읽고, 작업 내용은 그 브라우저에 저장된다 (새로고침해도 유지).

## 원고에서 읽는 표시 (블로그 원고 검수기와 같음)

| 원고 표시 | 확인 내용 |
|---|---|
| 빨간 취소선 | 캡션에 남아 있으면 `삭제 미반영` |
| 노란 형광펜 | 고친 문구가 캡션에 없으면 `수정 미반영` · `오타 수정 미반영` |
| 하늘색 형광펜 · 빨간 안내문(※…) | 검수 메모. 캡션에 그대로 남아 있으면 지적 |
| 워드 변경 내용 추적 | 삭제 · 추가 기록도 같은 방식 |

그 밖에 확인하는 것

- 해시태그 누락 · 오타 (인스타 규칙대로 이모지 · 문장부호에서 태그가 끝남. `#칠성사이다🥤` = `#칠성사이다`)
- @멘션 누락 · 오타
- 링크 누락 · 주소 다름 (프로필 링크로 넣는 경우는 무시)
- 숫자 다름, 같은 단어 두 번, 깨진 글자(`à` 등)
- 캡션 2,200자 · 해시태그 30개 한도

캡션에 없는 원고 문장은 영상 · 이미지에 넣은 문구일 수 있어서 `참고` 로만 보여 준다.
블로그 버전의 표 비교 · 제목 비교는 인스타에 없어서 뺐다.
